“的”字短语 · Verb + 的

📘 HSK 2–3 复习 ✏️ 自学 · 投屏 · 手机
📌 什么意思？ What does it mean?

Verb + 的 = “the one that …”

👉 东西大家都知道，就不用再说出来了。

📖 Meaning:
This pattern is used when we want to focus on the object (the thing), not the person or the action.
It's like saying in English:
“It is THIS thing that I bought / he did / you want...”
📌 怎么用？ How to use?
Object + 是 + Subject + 动词 + 的
(It is Object that Subject did / wants...)
我买的书→ 我买的 (the one I bought)
妈妈做的饭→ 妈妈做的 (the one Mom made)
昨天买的杯子→ 昨天买的 (the one bought yesterday)
写字的笔→ 写字的 (the one for writing)
🧩 Pattern:
Object + 是 + Subject + 买的/做的/要的... (It is Object that Subject did / wants...)
🧠 Compare:
Normal sentence
我买了一张票。
I bought a ticket.
Emphasized (this pattern)
这张票是我买的。
It is THIS ticket that I bought.
Normal sentence
他要红苹果。
He wants red apples.
Emphasized (this pattern)
红苹果是他要的。
It is RED APPLES that he wants.
✅ Key rules:
1. Put the object first.
2. Add 是 after the object.
3. Put the subject after 是.
4. End with 的 (and the verb if needed).
❓ Question form:
Object + 是 + Subject + 动词 + 的 + 吗？ = Is it Object that you (did)...?
这张票是你买的吗？ = Is it this ticket that you bought?
🎯 Quick summary:
“Object + 是 + Subject + (Verb) + 的”
= “It is OBJECT that SUBJECT (did something with).”
Use this when you want to stress WHAT thing, not WHO or WHEN.
📌 看例子 Examples
这本书是我买的。 It is this book that I bought.
这个杯子是昨天买的。 It is this cup that was bought yesterday.
这支笔是写字的。 It is this pen that is for writing.
✏️ 练习一 · 填空 Fill in the blank 动词 + 的
1. 这本书是我（______）。（买）
✅ 买的  — 这本书是我买的。
(= It is this book that I bought.)
2. 这杯咖啡 kāfēi · coffee 是妈妈（______）。（做）
✅ 做的  — 这杯咖啡是妈妈做的。
(= It is this cup of coffee that Mom made.)
3. 这个礼物是昨天（______）。（送）
✅ 送的  — 这个礼物是昨天送的。
(= It is this gift that was given yesterday.)
4. 这件衣服是姐姐（______）。（买）
✅ 买的  — 这件衣服是姐姐买的。
(= It is this dress that my older sister bought.)
✏️ 练习二 · 排句子 Put the words in order
📝 第一题

你的答案：________________________
✅ 这本书是你借的中文书吗？
（或者：这本书是你借的。）
(= Is it this Chinese book that you borrowed? / It is this book that you borrowed.)
📝 第二题

(= Is it these translation exercises that he did? / It is these exercises that he did.)

（或者：这些苹果是你要的。）
(= Is it these red apples that you want? / It is these apples that you want.)
📝 第四题
个 / 包裹 / 他 / 取 / 海运 bāoguǒ · 包裹 hǎiyùn · 海运 qǔ · 取

✅ 这个包裹是他取的海运包裹吗？
（或者：这个包裹是他取的。）
(= Is it this sea-freight package that he picked up? / It is this package that he picked up.)
💬 日常对话 Everyday conversation
A: 这张票是不是你买的？ (= Is it this ticket that you bought?)
B: 这张票不是我买的。我买的是下星期二的。 (= It's not this ticket that I bought. It's next Tuesday's that I bought.)
